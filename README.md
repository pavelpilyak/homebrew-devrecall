# homebrew-devrecall

Homebrew tap for [DevRecall](https://github.com/pavelpilyak/devrecall) — an
on-device developer activity aggregator.

## Install

```bash
brew tap pavelpilyak/devrecall
```

CLI:

```bash
brew install devrecall-cli
```

Desktop app (macOS):

```bash
brew install --cask devrecall
```
